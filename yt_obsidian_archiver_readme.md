## 📌 Sobre el Proyecto

**YT-Obsidian-Archiver** es una herramienta personal construida para facilitar el proceso de estudio y documentación. Esta extensión de Chrome automatiza la extracción de transcripciones y metadatos de videos de YouTube, transformándolos directamente en archivos Markdown estructurados. 

El objetivo principal es agilizar la ingesta de información valiosa hacia sistemas de gestión del conocimiento como **Obsidian** y **Google NotebookLM**, eliminando la fricción de copiar, pegar y formatear manualmente.

> **Nota:** Este proyecto nace como una herramienta de productividad personal y como un campo de pruebas para entender la arquitectura de las extensiones de navegadores y el desarrollo impulsado por IA (*Vibe Coding*).

## ✨ Características Principales

- **Extracción de Transcripciones:** Obtiene el texto completo de los subtítulos de los videos de YouTube.
- **Captura de Metadatos:** Recopila información clave como el título, autor y enlace del video.
- **Generación a Markdown:** Formatea automáticamente el contenido extraído en un archivo `.md` listo para usar.
- **Integración fluida:** Pensado específicamente para la estructura de bóvedas de Obsidian y cuadernos de Google NotebookLM.

## 🛠️ Tecnologías

- JavaScript (Vanilla)
- HTML / CSS
- Chrome Extensions API (Manifest V3)
- Asistencia de IA (Vibe Coding)
